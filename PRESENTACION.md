## 💼 Experiencia

### Desarrollador Full-Stack — Proyecto Académico: Tienda Virtual

Tienda virtual enfocada en mejorar la experiencia del usuario aplicando principios de **UX/UI**.

- **Front-end:** HTML, CSS y JavaScript para una interfaz amigable y funcional.
- **Back-end:** PHP para la lógica del negocio y MySQL para el almacenamiento de productos y usuarios.
- **Funcionalidades:** carrito de compras, gestión de usuarios y manejo de inventario.

### Proyecto de Estadía Profesional — ApSara · Pice Software

Aplicación móvil basada en el sitio web existente, con funciones mejoradas para optimizar la
experiencia del usuario.

- Desarrollada con **React Native**, **JavaScript**, **TypeScript** y **SQL**.
- Creación de una **API REST** para consumir los datos de la web, implementada con **Express** y **MySQL2**.

### Tienda-Node.js — este repositorio

Tienda en línea construida con **Node.js**, **Express**, **EJS**, **MySQL**, **Docker** y **Bootstrap**.

- Autenticación de usuarios con `bcrypt`, `express-session` y JWT.
- Panel de administración (dashboard) para productos, categorías, descuentos y compras.
- Carga de imágenes de productos con **Multer**.
- Base de datos MySQL ejecutándose en un contenedor **Docker**.
